Buat PIN AKPD

Jawaban angket kebutuhan murid bersifat rahasia (asas kerahasiaan kode etik BK). Buat PIN 4–8 angka untuk mengunci tampilan aplikasi di perangkat ini. Yang disimpan hanya hash PIN, di perangkat ini.

Ini kunci tampilan, bukan enkripsi: orang yang paham teknis dan memegang perangkat ini masih bisa membaca penyimpanan browser. PIN yang terlupa hanya bisa diatasi dengan menghapus semua data AKPD.

AKPD terkunci

Masukkan PIN guru BK untuk membuka data angket.

Penyimpanan browser tidak tersedia (mode privat?). Data hanya bertahan selama halaman terbuka. Gunakan ekspor JSON untuk menyimpan.
