Impor data Rapor Pendidikan

Gunakan file Excel Rapor PBD yang diunduh dari platform Rapor Pendidikan (berisi lembar "2. LAPORAN RAPOR", "2.1 REKOM. KESELURUHAN", "2.2 REKOM. PRIORITAS"). Data diproses di peramban Anda; tidak dikirim ke mana pun kecuali saat Anda memakai Asisten AI.

Seret satu atau banyak file .xlsx ke sini (tidak dibatasi, misalnya Rapor 2022–2026 sekaligus) atau

File dengan tahun terbaru otomatis menjadi data utama; file lain mengisi analisis tren. Templat input tren juga boleh ikut dipilih.

Cara memakai

  1. Unduh file Excel Rapor/PBD sekolah dari platform Rapor Pendidikan (raporpendidikan.kemendikdasmen.go.id), lalu impor di sini. Beberapa file dari tahun berbeda boleh dipilih sekaligus (lebih dari 5 pun bisa).
  2. Identifikasi (tab 1): baca ringkasan otomatis, capaian per indikator, penurunan, dan alarm dini sub-indikator.
  3. Tren 2–4 tahun (tab 2): lihat pola naik/turun antar tahun. Impor file Rapor PBD tahun-tahun sebelumnya atau isi nilai secara manual.
  4. Refleksi (tab 4): lihat indikator prioritas beserta akar masalahnya. Diskusikan dengan tim PBD (kepala sekolah, wakasek, guru, komite) dan pilih prioritas yang disepakati.
  5. Benahi (tab 5): pilih kegiatan, edit penanggung jawab, waktu, dan indikator keberhasilan, lalu unduh Excel RKJP + rancangan ARKAS atau laporan.
  6. Asisten AI (tab 6): minta analisis mendalam, narasi laporan rapat, program 1 tahun, atau ajukan pertanyaan sendiri.
Catatan: Akar masalah yang ditampilkan adalah hipotesis berbasis data, bukan kesimpulan pasti. Konfirmasi dengan data sekolah lain (supervisi kelas, angket murid, catatan BK, nilai harian). Penganggaran kegiatan mengikuti juknis BOSP tahun berjalan dan ketentuan pengadaan (SIPLah).

Memasang di Google Sites

Di Google Sites pilih Sisipkan → Sematkan → Sematkan kode, lalu tempel seluruh isi file HTML ini. Untuk Asisten AI di luar claude.ai, isi API key Gemini di tab 6.
